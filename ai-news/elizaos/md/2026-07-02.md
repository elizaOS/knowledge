## Plugin Release

- GBLIN released plugin-gblin version 0.2.4 for Eliza agents
- New action GET_GBLIN_RISK_ATTESTATION introduced, enabling agents to pay $0.003 via x402 in USDC on Base gaslessly
- Action returns a 10-minute EIP-712-signed proof of the current BTC/ETH risk regime
- Proof can be attached to subsequent agent actions and verified by any counterparty at no cost
- Additional features include treasury health checks, idle USDC parking into an on-chain index, and JIT-swaps back to USDC for invoice payments
- Plugin includes 4 actions and 1 provider running against live Base mainnet
