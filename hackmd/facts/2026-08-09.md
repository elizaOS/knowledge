# Fact Briefing: 2026-08-09

## Overall Summary
The ElizaOS project has officially abandoned its token following a class-action lawsuit settlement that depleted resources, pivoting to a pure open-source software model. Simultaneously, the technical core has stabilized with a major production release promoting features like app-mode onboarding, cross-origin SSO, and enhanced voice capabilities.

## Key Facts

- Shaw Walters officially declared the ElizaOS token 'dead' following a $400k settlement in the Burwick lawsuit that exhausted foundation resources.
- The project has pivoted to a smaller, focused team focusing exclusively on open-source AI agent software, decoupled from token economics.
- PR #17865 was merged, promoting 448 commits from develop to main including billing fixes, app-mode onboarding, and SSO parity.
- ElizaOS partnered with a private compute and phone company to integrate the framework as a native operating system.
- The eliza.army leaderboard and contribution tracking system were launched to formalize and reward community development efforts.
- Security boundaries were strengthened via PR #17643 which now rejects caller-authored system policies at the per-agent boundary.
- Fish Audio streaming TTS integration was added to the framework to enable faster real-time voice conversations.
- Wolf Popper law firm is reportedly preparing paperwork for a class-action lawsuit against Shaw Walters personally.
- Technical development has standardized on Bun runtime version 1.3.14 to ensure consistent performance across all workflows.
